(static) encodeParamId(shootingMode, category, cameraId, paramIndex) → {string}

Description:
  • Encode a paramId from its constituent parts. paramId layout (64-bit): bits 63..56 = shootingMode (e.g. 0=photo, 1=video, 2=astro) bits 55..48 = category (parameter group) bits 47..44 = cameraId (0=tele, 1=wide, 15=shared) bits 43..8 = reserved (0) bits 7..0 = paramIndex (parameter index within the category) Returns a decimal string suitable for protobuf.js int64 fields.
